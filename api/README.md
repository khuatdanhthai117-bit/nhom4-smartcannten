# API

Điểm bắt đầu cho API serverless khi triển khai lên Vercel hoặc nền tảng tương tự.

Hiện tại bản local cung cấp:

- `GET /api/health` — trạng thái máy chủ.
- `GET /api/menu` — thực đơn minh hoạ.

Các API tiếp theo cần chuyển từ logic demo phía trình duyệt: xác thực, giỏ hàng, đơn hàng, kho, đánh giá và báo cáo.
